# 📈 Bot de Sinais IQ Option com Envio via Telegram

Este bot monitora pares de opções binárias na IQ Option, gera sinais com base em RSI e Média Móvel, e envia alertas automaticamente para um grupo no Telegram.

## 🚀 Funcionalidades

- Conexão com IQ Option (modo prática ou real)
- Análise de pares com RSI e Média Móvel
- Envio de sinais formatados para o Telegram
- Suporte a múltiplos pares e níveis de gale
- Configuração 100% via `config.json`

## ⚙️ Requisitos

- Python 3.8+
- Conta na IQ Option
- Bot e grupo/canal no Telegram
